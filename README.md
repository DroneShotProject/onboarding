# onboarding

DroneShotProject の開発に参加するための環境構築・開発フローの手順書です。

Windows と macOS の両方に対応しています。各手順の見出しに `[Windows]` / `[macOS]` が
付いている場合は、自分の OS に合わせて読み進めてください。付いていない箇所は共通です。

## セットアップ

| # | ドキュメント | 内容 |
| --- | --- | --- |
| 01 | [GitHub アカウント](docs/onboarding/setup/01_Github.md) | GitHub アカウントの作成と Education 登録 |
| 02 | [ターミナル](docs/onboarding/setup/02_Windows_Terminal.md) | Windows Terminal / macOS ターミナル（Homebrew） |
| 03 | [Visual Studio Code](docs/onboarding/setup/03_VisualStudioCode.md) | エディタのインストールと拡張機能 |
| 04 | [Android Studio](docs/onboarding/setup/04_AndroidStudio.md) | JDK 17 / Android SDK（Windows は必須、macOS は任意） |
| 05 | [Git](docs/onboarding/setup/05_Git.md) | Git のインストールと初期設定 |
| 06 | [DSP](docs/onboarding/setup/06_DSP.md) | DroneShotDJI のクローンとビルド・実機インストール |
